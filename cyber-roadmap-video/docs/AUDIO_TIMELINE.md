# Audio Timeline · Music Cue Sheet · SFX Cue Sheet

All timings are derived in code from `src/timeline.ts` + `src/content.ts`
(`src/audio/cues.ts → buildCues()`), so changing a scene boundary moves its
sounds and animations together. Every track is optional: `AudioLayer` checks
`getStaticFiles()` and skips any file that is not in `public/audio/`.
